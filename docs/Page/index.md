# Heat Generator

A small Flutter utility for cold times.

[Documentation](documentation.html) | [Install](install.html) | [Source](https://github.com/YunaBraska/Heat-Generator-App)

## What it does

- Uses processor load as a pocket warmer.
- Is available as source for Flutter-supported platforms.

## Availability

There is no supported macOS release yet. Any future external package needs normal Developer ID signing and notarization. App Store distribution needs separate policy review because the product intentionally heats devices.
